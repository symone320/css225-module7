# Module 7: Creating and Using Python Functions

This repository contains my Python programs for the Module 7 Lab Activity. The purpose of this lab was to practice creating and calling functions, working with lists, using the Turtle module, and working with Python classes.

## Programs

**Problem1AreaOfCircle.py**
Calculates the area of a circle using a function and the Python `math` module.

**Problem2CheckRange.py**
Checks whether a number is within the range of 1 through 9 and prints the result.

**Problem3MulitplyList.py**
Uses a function to multiply all numbers in a list.

**Problem4Unique.py**
Creates a new list containing only the unique values from the original list.

**Problem5Squares.py**
Uses Python's Turtle module and a function to draw nested squares.

**Problem6ClassCar.py**
Demonstrates Python classes, attributes, and methods. The original car class was modified to include type and manufacturer attributes and their corresponding methods.
